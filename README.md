# CarCare

CARCARE — современное веб- и мобильное приложение для учёта расходов, заправок, техобслуживания и штрафов для частных автолюбителей.

## Первый запуск: быстрый старт
1. **Откройте приложение** — при первом запуске появится welcome-экран с кратким описанием возможностей.
2. **Зарегистрируйтесь** — выберите регистрацию по email или через Яндекс/Google. Введите email и пароль, следуйте подсказкам.
3. **Подтвердите email** (если требуется) — проверьте почту и перейдите по ссылке из письма.
4. **Войдите** — используйте свои данные для входа.
5. **Проверьте профиль** — заполните имя, добавьте авто, загрузите фото. Это поможет начать вести учёт расходов и событий.

> После регистрации вы можете:
> - Добавить автомобиль и его параметры
> - Изучить основные разделы: Топливо, ТО, Штрафы, Отчёты
> - Настроить виджеты на главной странице

Интерфейс интуитивен, все основные действия доступны с главной страницы. Если возникнут вопросы — смотрите подробную документацию или обратитесь в поддержку.
