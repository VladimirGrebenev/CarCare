# CarCare

CARCARE — современное веб- и мобильное приложение для учёта расходов, заправок, техобслуживания и штрафов для частных автолюбителей.

## Технологический стек

- **Бэкенд:** Go 1.23
- **Фронтенд:** Svelte 5.x, SvelteKit 2.x, Vite 8.x
- **База данных:** PostgreSQL
- **Тестирование:** Vitest 4.x (unit/integration), Playwright (e2e)

## Доменная модель

Приложение работает со следующими сущностями:

- **User** — пользователь (регистрация по email или через Яндекс/Google)
- **Car** — автомобиль (марка, модель, год, VIN, госномер, пробег)
- **Fuel** — заправки (дата, объём, тип топлива, цена, пробег, АЗС)
- **Maintenance** — техобслуживание (дата, тип работ, пробег, стоимость, описание, сервис)
- **Fine** — штрафы (дата, номер постановления, сумма, статья, статус оплаты)
- **Report** — отчёты и статистика по расходам

## Основные возможности

- Добавление и управление несколькими автомобилями
- Учёт заправок: объём, тип топлива, цена, пробег
- Учёт ТО: замена масла, шин, ремонт и т.д.
- Учёт штрафов с отслеживанием статуса оплаты
- Отчёты и статистика расходов
- Виджеты на главной странице
