# Профиль и настройки

## Регистрация

1. На странице входа нажмите **Зарегистрироваться**
2. Выберите способ регистрации:
   - **Email** — укажите email и пароль
   - **Яндекс** — через аккаунт Яндекса
   - **Google** — через аккаунт Google
3. Подтвердите email (если требуется) — перейдите по ссылке из письма
4. Войдите в приложение

## Редактирование профиля

1. Нажмите на аватар в правом верхнем углу
2. Выберите **Профиль**
3. Вы можете изменить:
   - Имя
   - Фото
   - Email
   - Пароль

## Настройка виджетов

На главной странице можно настроить отображение виджетов:
1. Нажмите **Настроить виджеты**
2. Выберите, какие виджеты отображать
3. Перетащите их в нужном порядке
4. Нажмите **Сохранить**
