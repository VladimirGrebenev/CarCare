# Техобслуживание

## Добавление записи о ТО

1. Перейдите в раздел **Техобслуживание**
2. Нажмите **Добавить ТО**
3. Заполните поля:
   - **Дата** — дата проведения работ
   - **Тип работ** — выберите из списка:
     - Замена масла
     - Замена шин
     - Технический осмотр
     - Ремонт
     - Страховка
     - Другое
   - **Пробег** — пробег на момент ТО
   - **Стоимость** — сумма работ и запчастей
   - **Описание** — подробное описание работ (опционально)
   - **Сервис** — название автосервиса (опционально)
4. Нажмите **Сохранить**

## История ТО

В разделе отображается хронология всех работ по автомобилю. Вы можете:
- Фильтровать по типу работ
- Смотреть общую сумму затрат на ТО
- Видеть периодичность обслуживания
