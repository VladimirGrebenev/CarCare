# Штрафы

## Добавление штрафа

1. Перейдите в раздел **Штрафы**
2. Нажмите **Добавить штраф**
3. Заполните поля:
   - **Дата** — дата нарушения
   - **Номер постановления** — номер документа о штрафе
   - **Сумма** — размер штрафа
   - **Статья** — статья нарушения (например, 12.9 КоАП — превышение скорости)
   - **Описание** — обстоятельства нарушения (опционально)
   - **Статус оплаты** — оплачен / не оплачен
4. Нажмите **Сохранить**

## Отметка об оплате

1. Найдите штраф в списке
2. Нажмите **Оплатить**
3. Статус изменится на "Оплачен"

## Просмотр статистики

В разделе доступна статистика:
- Общая сумма штрафов
- Количество неоплаченных штрафов
- Сумма к оплате
