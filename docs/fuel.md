# Учёт топлива

## Добавление заправки

1. Перейдите в раздел **Топливо**
2. Нажмите **Добавить заправку**
3. Заполните поля:
   - **Дата** — дата заправки
   - **Объём (л)** — количество литров
   - **Тип топлива** — АИ-92, АИ-95, АИ-98, Дизель, Газ
   - **Цена за литр** — стоимость одного литра
   - **Общая стоимость** — итоговая сумма (может рассчитаться автоматически)
   - **Пробег** — показания одометра на момент заправки
   - **АЗС** — название заправочной станции (опционально)
   - **Полный бак** — отметьте, если заправились полностью
4. Нажмите **Сохранить**

## Расчёт расхода топлива

Приложение автоматически рассчитывает расход топлива (л/100 км) на основе:
- Объёма заправки
- Пробега между заправками
- Отметки "Полный бак"

## Просмотр истории

В разделе **Топливо** доступен список всех заправок с возможностью:
- Фильтрации по дате
- Сортировки
- Просмотра статистики (общий расход, средняя цена и т.д.)
